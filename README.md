## About

UserVault is a customer data management Android application built using Kotlin and Jetpack Compose. The app allows users to store, search, update, backup, and restore customer information locally on the device.

## ✨ Features

* Add customer records
* Edit and delete customer information
* Search customers by phone number
* Store customer name, mobile number and address
* Backup and restore data
* Offline-first local storage
* Modern Material 3 UI

## 🛠 Tech Stack

* Kotlin
* Jetpack Compose
* MVVM Architecture
* Room Database
* Coroutines
* StateFlow
* Material 3

## 📱 Key Functionalities

* Customer Management
* Quick Search
* Local Database Storage
* Data Backup & Restore
* Responsive UI Design
